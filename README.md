## English

### What it adds

- Godzilla, the King of the Monsters: 50,000 health, 1,000 damage, area attacks and a nuclear flash. Walks on land and swims in the ocean.
- King Kong: 10,000 health and 1,000 damage.
- Godzilla Power and King Kong Power traits.
- A Monsters tab with a spawn button for each one.

This is the original mod. The new [Godzilla](https://github.com/AgricheX/Godzilla) mod for current WorldBox is its successor.

### How to install

1. Install NCMS for WorldBox 0.14.
2. Download **MonsterMod.zip** with the link above.
3. Extract it into the `Mods` folder of your WorldBox installation, so you get `Mods/Monster Mod/mod.json`.
4. Start the game.

## Português (Brasil)

### O que o mod adiciona

- Godzilla, o Rei dos Monstros: 50.000 de vida, 1.000 de dano, ataque em área e flash nuclear. Anda em terra e nada no oceano.
- King Kong: 10.000 de vida e 1.000 de dano.
- Traços Poder do Godzilla e Poder do King Kong.
- Uma aba Monstros com botão de invocação para cada um.

Este é o mod original. O novo mod [Godzilla](https://github.com/AgricheX/Godzilla), para o WorldBox atual, é o sucessor dele.

### Como instalar

1. Instale o NCMS para o WorldBox 0.14.
2. Baixe o **MonsterMod.zip** pelo link acima.
3. Extraia na pasta `Mods` do WorldBox, de forma que fique `Mods/Monster Mod/mod.json`.
4. Abra o jogo.
